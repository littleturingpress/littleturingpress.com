# littleturingpress.com

Website for *The Little Turing Codebreakers* book series by Chinar Kakutsey.
Static HTML/CSS, hosted on GitHub Pages. No build step, no cookies, no tracking.

- `index.html` – home page
- `impressum.html`, `datenschutz.html` – legal pages (German law). Fill in every yellow `[...]` field before launch.
- `assets/` – styles, script, self-hosted fonts (Inter, DejaVu Sans Mono; licences included), images, free starter pack PDF
- `CNAME` – custom domain for GitHub Pages

After the book is live on Amazon, replace the search links in `index.html` with the direct product links.
